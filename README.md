# 🧮 Calculadora de Distratos (V4 Company)

![Status](https://img.shields.io/badge/status-conclu%C3%ADdo-green)

Este projeto é uma calculadora web desenvolvida para otimizar e facilitar o complexo processo de cálculos contratuais de distrato, focada no ecossistema da V4 Company.

---

## 🎯 O Problema

Anteriormente, o cálculo para um distrato (rescisão de contrato) era um processo manual, "bruto e engessado". Isso exigia que tanto os franqueados quanto a equipe interna da empresa tivessem que montar um raciocínio complexo do zero para cada caso, aumentando o tempo gasto e a chance de erros.

## 💡 A Solução

Esta ferramenta foi criada para automatizar e simplificar esse processo. Com a calculadora, o usuário precisa apenas ter o contrato em mãos.

A aplicação abstrai a lógica de negócio e permite que, com a inserção de alguns dados contratuais básicos, o sistema calcule automaticamente todos os valores devidos, multas e taxas, fornecendo o resultado final do distrato de forma rápida e confiável.

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estrutura da página)
* **CSS3** (Estilização)
* **JavaScript** (Toda a lógica de cálculo e regras de negócio)
